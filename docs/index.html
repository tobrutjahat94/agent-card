How it works

  • One-shot: you register exactly once. No daily check-in, no upkeep.
  • Bound to your token: the contract verifies ownerOf(tokenId) == you on-chain. Your card is proof you own that Agent ID — stronger than a simple “holds any ID” gate.
  • Your data, on-chain: tokenId, endpoint and message are stored publicly. Nothing else is collected.
  • Agentic Wallet holders: the Agentic Wallet does not sign arbitrary contract calls by default. Use Developer Mode in the Binance App (Agentic Wallet → Settings → Developer Mode), then call register() — see the Agent Guide for the exact steps, including the baw contract-call commands.
  • No owner: the contract has no owner, no admin functions, no pause, no upgrade, no fund custody. Nobody — not even the deployer — can change or delete your card.
